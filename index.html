1Atomic Structure ⭐ Know the basics

🧱Atom = the tiny building block that all matter is made of. Everything around you is atoms.
ParticleChargeWhere?
Proton+1Nucleus (centre)
Neutron0Nucleus (centre)
Electron−1Shells around the nucleus
💡Proton = Positive. Neutron = Neutral. Electron = the negative one, zooming around the outside.

Atoms are neutral overall: number of protons (+) = number of electrons (−), so they cancel out.

2History of the Atom Model ⭐ Know the basics

💡Order: Dogs Don’t Throw Rubber Bones = Democritus, Dalton, Thomson, Rutherford, Bohr
📈Each scientist added something: Dalton = solid ball → Thomson added electrons → Rutherford added the nucleus → Bohr put electrons in energy levels (shells).
Rutherford’s experiment (the famous one): he fired tiny particles at gold foil.
  • Most went straight through → atoms are mostly empty space.
  • A few bounced back → there’s a tiny, dense, positive nucleus.

3Elements & Atomic Number ⭐⭐⭐ Top priority

🔑Element = a pure substance made of only one type of atom (e.g. all oxygen).
Atomic number = the number of protons. It never changes for an element, so it’s the element’s ID.
Try it: add protons
1 proton20 protons
💡Change the number of protons → you get a different element. 6 protons is always carbon. 7 protons is always nitrogen.

4Mass Number & Particles ⭐⭐⭐ Top priority

🔑Mass number = protons + neutrons (the heavy particles in the nucleus; electrons are almost weightless)

Protons

= atomic number

Electrons

= protons (neutral atom)

Neutrons

= mass number − atomic number

23Na11

Top = mass number (23). Bottom = atomic number (11).

Worked example: sodium

Protons = 11
Electrons = 11
Neutrons = 23 − 11 = 12

⚠️Common mistake: don’t put electrons in the mass number. Mass number = protons + neutrons only.

5How the Periodic Table Developed ⭐ Know the basics

Before 1869

Patterns spotted

Scientists found lots of elements and noticed some behave alike.

1869

Mendeleev’s table

Lined elements up by atomic mass. Similar ones went in the same column.

1869

He left gaps

He said the gaps were undiscovered elements and predicted their properties.

Later

He was right!

New elements (gallium 1875, germanium 1886) fit the gaps. Today’s table is ordered by atomic number.

Mendeleev-style table (gaps = ?)

🧠Key idea: Mendeleev left gaps because he trusted the pattern and believed elements were still waiting to be discovered.

8Elements, Compounds, Mixtures & Molecules ⭐⭐⭐ Top priority

Element

One type of atom only.
O₂, Fe, He

Compound

2+ different elements joined (chemically bonded).
H₂O, CO₂, NaCl

Mixture

2+ substances just mixed, not joined.
air, salt water

Molecule

2+ atoms joined together.
O₂ and H₂O are both molecules

What they look like (particle diagrams)

💡Quick test: Are the atoms joined? No → mixture (or lone atoms). Yes, all the same kind → element. Yes, different kinds → compound.
⚠️Compound vs mixture: you can’t easily separate a compound (needs a chemical reaction). A mixture can be separated by physical means, like filtering or evaporating.

Formula decoder: how many atoms?

🔑The small number (subscript) multiplies the atom just before it. No number = 1.
H₂O → H×2 + O×1 = 3 atoms. A number out the front (like 2H₂O) multiplies everything.
